# 风格配方库（style_lib）

> Office 文档专家「卫文档」的风格库——风格配方 = 配色板 + 字体对 + 版式规则 + 画布格式。

## 配方规范

```
<风格名>/
├── palette.md       # 配色板（角色/色值/用途）
├── fonts.md         # 字体对（标题/正文/数字）
├── layout.md        # 版式规则（边距/卡片/信息层级）
└── canvas.md        # 画布格式（16:9/4:3/竖屏/海报）
```

## education_modern（默认配方摘要）

### 配色板
| 角色 | 色值 | 用途 |
|---|---|---|
| 主蓝 | #2563EB | 标题/强调 |
| 深蓝 | #1E3A8A | 深色文字/页脚 |
| 亮青蓝 | #06B6D4 | 点缀/图标 |
| 暖橙 | #F59E0B | 强调/闸门 |
| 珊瑚 | #FB7185 | 警示/高亮 |
| 白 | #FFFFFF | 背景主 |
| 浅蓝底 | #EFF6FF | 卡片/区块底 |
| 灰文字 | #475569 | 正文 |

### 字体
- 标题：微软雅黑 Bold（思源黑体备选）
- 正文：微软雅黑 Regular
- 数字：Arial Bold

### 版式
- 每页 1 主视觉焦点 + 1 标题 + 2-4 要点卡片
- 页边距 60px，卡片间距 20px，留白克制
- 封面：全屏渐变 + 大标题 + 课程标签
- 背景：渐变填充 + 半透明光晕椭圆（光影流动）

### 画布
- 默认 16:9（1280×720）；竖屏/海报按需

## 新增风格流程
1. 调色板 + 字体对 → 2. 生成样例页（卫文档）→ 3. 注册到本 README → 4. 验证
