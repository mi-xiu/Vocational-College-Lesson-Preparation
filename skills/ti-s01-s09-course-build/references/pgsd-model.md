# PGSD 能力模型参考

PGSD 是职教课程开发中常用的四维能力模型，把岗位能力拆成：

- **P Professional（职业素养）**
  - 职业道德、职业规范、团队协作、安全意识、质量意识、服务意识、工匠精神等。
  - 表现：遵守行业规范、按时交付、对工作结果负责。

- **G Generic（通用能力）**
  - 沟通表达、自主学习、信息素养、批判性思维、创新意识、工具使用、问题解决等。
  - 表现：能检索资料、能写清晰报告、能跨部门沟通。

- **S Specialty（专业技能）**
  - 岗位核心硬技能，直接对应工作任务。编号建议 S1、S2…Sn。
  - 表现：能独立完成岗位典型任务，产出符合要求的作品/产品/服务。

- **D Developmental（发展能力）**
  - 适应变化、岗位迁移、数字素养、终身学习、创新创业等。编号建议 D1、D2…Dn。
  - 表现：能跟踪行业新技术、能从 A 岗位迁移到相近 B 岗位。

## 使用方式

1. 基于岗位矩阵，逐条列出工作任务。
2. 对每条任务，问：完成它需要 P/G/S/D 中哪些能力？
3. 把能力聚类、去重，形成能力点清单。
4. 为每个能力点写可观测行为，再按初级/中级/高级分级。

## 与课标对接

- 课程目标：用 PGSD 四维写知识/能力/素质目标。
- 内容模块：一个模块可对应若干 S 能力点。
- 考核标准：初级=合格，中级=良好，高级=优秀。
