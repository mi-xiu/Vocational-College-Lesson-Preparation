# 典型工作任务分析框架（K 系列支撑文档写法）

本文件给 `ti-s06-course-blueprint` Step 1 用。产出《典型工作任务分析》，归入课程知识库 `01_课程顶层设计/`，作为"为什么这么教"的学理支撑文档。

---

## 文档结构建议

```markdown
# 典型工作任务分析（<课程名>）

## 一、典型工作任务的界定与一级任务
- 定义：典型工作任务 = 职业中具"结构完整工作过程"、能反映职业核心能力的任务单元
- 一级典型工作任务（本课程唯一或主线的那条，如"完成一条短视频从创意到上线的全流程创作"）

## 二、建立典型工作任务的思路（逆向设计）
岗位典型任务 → 工作过程六步 → 学习领域（模块 M1…Mn）→ PGSD 能力 → 考核分级
（附"建立流程"示意图）

## 三、方法（7 种可操作工作法）
BAG 实践专家研讨会 / 工作过程六步法 / DACUM / 典型情境锚定 / PGSD 结构化 / 学习性转化 / 技能点分解法

## 四、理论依据
工作过程系统化 / 行动导向 / 情境学习 / 建构主义 / CBE / 迁移 / UbD 逆向设计

## 五、模块 ↔ 典型工作任务映射（含核心技能点）
| 学习性子任务（模块） | 对应典型任务环节 | 核心技能点（S/G/P/D） |
|---|---|---|
| M1 行业认知 | 资讯 | G1、P2 |
| M3 拍摄实务 | 实施-拍摄 | S2 |
| ... | ... | ... |

## 六、技能点分解（单一数据源）
每个 PGSD 能力点 × 初级/中级/高级 三档可观测实施要素，标对应岗位与模块。
（详表见《技能点分解》独立文档，本处引用）

## 七、能力落点：PGSD 技能点分解与典型工作任务的咬合
- 8 模块 ↔ 技能点支撑关系，证明每个任务由 1–4 个能力点实施要素"撑起"
- 分级落地：初级=入门项目 / 中级=主线项目（及格）/ 高级=冲刺项目

## 八、速查表
任务—能力—技能点（可测）—分级—载体 一条线
```

## 与整体设计的衔接

典型工作任务分析回答"为什么这么教"，整体设计回答"具体教什么项目、怎么排"。两者关系：

- 分析的"一级典型工作任务" → 整体设计的"项目载体"（如"短视频全流程创作" → "某真实项目账号运营"）。
- 分析的"模块 ↔ 技能点" → 整体设计的"模块 × 项目 × 技能点 咬合矩阵"。
- 分析的"分级（初/中/高）" → 整体设计的"阶梯式项目（P1/P2/P3）"与考核占比。
