# 资源条目字段标准与分类体系

本文件是 SKILL.md 的补充，定义资源条目的完整字段、分类细则和质量标准。生成资源清单时按此执行。

## 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 标题 | 资源名称，用原标题或能概括内容的简短名 | 《短视频运镜 12 招》 |
| 类型 | 三选一：视频/微课 · 图文/文档 · 工具/素材 | 视频/微课 |
| 来源 | 平台名 + 链接（网络资源）或本地路径（本地文件） | B站 · https://...  /  /项目盘/K02_01/分镜模板.docx |
| 对应能力点 | 挂到能力图谱的哪个节点，写能力点编号或名称 | K02_01-03 构图 |
| 简介 | 一句话说清楚讲什么、有什么用，不超过两行 | 讲解推拉摇移跟五种基础运镜，含实操演示 |

## 选填字段

| 字段 | 说明 |
|------|------|
| 质量标注 | 精读可用 / 需二次加工 / 仅参考 |
| 时长/篇幅 | 视频注明时长，文档注明字数或页数 |
| 更新日期 | 资源发布或更新时间，判断是否过时 |
| 关联资源 | 与其他条目的关联（如本地文件对应的网络原版） |

## 三大资源类型细分

### 视频/微课
教学视频、案例演示、运镜示范、软件操作录屏等。判断标准：可播放、有教学演示价值。纯娱乐或纯宣传的不收。

### 图文/文档
教程文章、剧本模板、分镜表、课程标准、操作手册等。判断标准：有可复用的知识点或模板结构。碎片化的朋友圈式短文不收。

### 工具/素材
剪辑软件、拍摄器材、灯光布光方案、配乐素材、转场模板等。判断标准：能直接用于教学实操或学生练习。纯广告导购内容不收。

## 能力点挂载规则

- 一条资源可挂多个能力点，但必须至少挂一个。挂不上任何能力点的，要么能力图谱不全，要么这条资源跟本课程无关，不要硬塞。
- 挂载到最细的能力点层级，不要只挂到模块顶层。挂在"K02_01"不如挂在"K02_01-03 构图"，越细越好用。
- 能力点编号优先用项目文件里的现成编号，保持与课程标准一致。

## 去重规则

- 标题完全相同或内容高度相似（同一作者搬运）：保留信息更完整的，其余合并备注。
- 本地文件 + 网络资源讲同一主题：两条都保留，在"关联资源"字段互相标注。本地文件可能已经过二次加工，有独立价值。
- 同一主题不同角度（如一个是入门教程一个是进阶技巧）：都保留，不视为重复。
