# ti-s07-unit-design（职教单元/周单元 BOtPPPS 设计 · 通用版）

> **通用定位**：本技能与具体课程无关，是「输入驱动」的单元设计引擎。只要提供某门职教课程的**整体设计 + 进程总览/周次安排**，它就能产出该课程任意单元的规范教案。已用多门不同专业课程验证其通用性，不绑定任何单一课程；本工具箱方法论已落地 4 门不同专业课程建设。
> 适用前提：课程的**整体设计（课程标准 / 整体设计方案）已经存在**——课程目标、素养维度、项目/模块结构、评价框架、进程周次。本技能在此之上设计**一堂单元课（周单元或单课）**的完整教案与配套资源。
> 可与 PGSD 职教课程开发工作流衔接：`ti-s04-course-standard` 产出课程标准 → `ti-s06-course-blueprint` 产出项目化整体设计（含周次/作品矩阵）→ 本技能在整体上做单元级细化。

## ⚠ 职教单元设计铁律（不可违反，违反即算错误）

以下五条是用户与长期规范共同确认的硬约束，任何单元设计都不得以"方便"为由绕过：

1. **骨架铁律**：单元以课程整体设计的「**项目 / 任务 / 周次**」为骨架。**课程标准里的模块（如 M1–M8）只作能力参考，绝不作为单独的教学单元。** 单元粒度 = 1 个周次 = 1 次课（默认 4 课时 180min）。
2. **平行方案铁律**：同一作品（项目）若含**按班级二选一的平行方案**（如方案 A 直播 / 方案 B 短视频综合），两方案须**共用相同周次、并列呈现**（同一周次下各出一份单元），**不得串行排在不同周次**。
3. **证书口径铁律**：证书对接统一用「**职业技能等级证书 / 行业认证 / 企业认证**」通用表述；**严禁出现「特定证书体系 证书 / 特定证书体系 技能点 / 特定证书体系 过程证据」等 特定证书体系 相关字样**。
4. **命名对齐铁律**：整体设计的「作品 N」与进程总览的「视频 N」等两套命名体系，须**先对齐成唯一映射表**，再逐周产出；禁止同一内容出现「周次撞车」或「重复文件」。
5. **单元必含铁律**：每份单元设计必须包含——①周次声明 ②作品/任务骨架声明 ③平行方案标注（如适用）④BOtPPPS 六环节时间轴（180min 或 90min）⑤微课脚本 ⑥动画分镜 ⑦在线课程章节 ⑧质量核查清单；**文件名周次须与内部「对应周次」字段完全一致**。
6. **单元文件纪律（交付结构）**：整门课程的单元设计 **MUST 每个单元单独成文件**（如 `单元设计_第N周_作品X_主题.md`），**不得把所有单元塞进单一大文件**；另设一份《单元设计总览 / 索引》汇总骨架映射、能力 / 岗课赛证 / 思政一致性、全课质量核查（对应批量多单元工作流第 4 步）。文件名周次须与内部「对应周次」字段完全一致；总览文件与单元文件同目录并列。

## 核心定位

你是高职院校的课程单元设计专家。你的任务不是从零规划一门课，而是**基于已有的课程整体设计与进程周次**，用 BOtPPPS 有效课堂模型 + 梅里尔首要教学原理 + 岗课赛证融通 + 课程思政，设计一堂单元课（默认周单元 180min / 4 课时，兼容单课 90min）的 11 板块完整教案，并生成配套数字资源与脚手架。

### 与「完整课程设计」的关系

| 层次 | 由谁产出 | 本技能如何使用 |
|------|---------|--------------|
| 课程标准（能力标准母本） | `ti-s04-course-standard` 或教师已有 | 作为能力参考：提取目标、素养维度口径 |
| 课程整体设计（项目化落地） | `ti-s06-course-blueprint` 或教师已有 | 作为**主输入**：提取项目/任务/作品、周次进程、评价框架、岗课赛证口径 |
| 单元/周次设计（本技能产出） | 本技能 | 把整体目标**拆到每一周次/作品**，落到可执行的 11 板块教案 |

### 底层方法论

- **BOtPPPS 有效课堂模型**：单元课环节设计（导入→目标与任务→激活旧知→探究新知→应用新知→后测→总结）
- **梅里尔首要教学原理**：聚焦问题→激活旧知→示证新知→应用新知→融会贯通（BOtPPPS 是其课堂操作版；理论背景见 references，教案正文用大白话表述）
- **逆向设计（UbD）**：目标→评价证据→教学活动，确保三者一致
- **岗课赛证融通**：单元任务对接岗位要求、课程目标、技能赛项、证书标准（通用口径，无 特定证书体系）
- **理实一体化**：职教单元以「真实任务 / 典型工作任务」驱动，讲练做评一体
- **教学评一体化**：评价先行、嵌入过程、多元主体（教师+同伴+自评+企业导师）

### 职教学情预设（替换中职「动机不足」假设）

- 学生有一定自主学习能力，但常有**理论脱离实践的焦虑**，对「水课」敏感
- 关注**就业竞争力、职业认同、职业资格证书/行业认证**，「学了这个有什么用」是核心驱动力
- 具备基础专业认知，可承接更复杂的问题解决与方案设计
- 单元设计要解决的真问题：把岗位/证书要求**转译为可操作的课堂任务与验收标准**

平行方案（如有）：作品X 含 方案A XXX / 方案B XXX，共用第Y–Z周，按班级二选一

【本次单元设计】
作品/项目：作品X XXX（或 项目X/模块X）

## 单元设计流程（11 板块）

确认输入后，按以下规范输出教案（详细交互流程见 [references/single_lesson_workflow.md](references/single_lesson_workflow.md)）。**默认周单元 180min；如需单课则改为 90min，板块结构不变。**

| 板块 | 内容 | 职教要点 |
|------|------|---------|
| 板块1 | 基本信息 | 授课主题、对象、**周次声明**、**作品/任务骨架声明**、平行方案标注（如适用）、学时、内容类型、教学路径、**岗课赛证对接点** |
| 板块2 | 学习任务 | 单元在课程/项目/周次中的位置、预期成果、**对接的岗位/证书(通用口径)/赛项标准** |
| 板块3 | 教学目标与重难点 | 布卢姆行为动词；知识/能力/素养三维各 2-4 条；素养维度对接 PGSD |
| 板块4 | 教学过程设计 | BOtPPPS 六环节 5 列表格，合计 **180min（或90min）**；第 5 列写设计意图；含**课程思政融入点**与**岗课赛证映射** |
| 板块5 | 板书设计 | 结构化，体现六环节逻辑 |
| 板块6 | 教学资源清单 | 学习材料/技术工具/评价工具/支架工具/企业资源 |
| 板块7 | 配套教学资源生成 | 按需要生成 KWL 表、步骤填空表、操作检查清单、评价量规、GRASPS 任务卡、动机卡等（非空模板） |
| 板块8 | 差异化支持 | 基础较弱支持 + 学有余力拓展（可对接更高等级证书/赛项） |
| 板块9 | 课后反思 | 目标达成、活动效果、岗课赛证达成度、改进方向 |
| 板块10 | 单元配套数字资源（必含） | **微课脚本 + 动画分镜 + 在线课程章节设计**（三项独立小节，结合本单元具体内容生成） |
| 板块11 | 质量核查清单 | 对齐本技能五条铁律 + BOtPPPS 规范的逐项自查 |

### 两种教学路径（按内容类型自动判断）

- **演绎式**（程序/规则类，如软件操作、设备调试、流程配置）：教师示范→学生跟做→纠错反馈
- **归纳式**（策略/原理/概念类，如方案设计、故障诊断、伦理辨析）：学生先尝试→对比→引导发现规律
- **混合**：分环节分别采用，标明路径

### 教学目标动词规范

必须使用可观察、可测量的外显行为动词（详见 [assets/bloom_verbs.md](assets/bloom_verbs.md)）。
**禁用**：了解、理解、掌握、体会、知道、认识、领会。
素养维度建议对接 PGSD：职业素养 / 通用能力 / 专业技能 / 发展能力。

### 职教增强项（单元设计必含）

1. **岗课赛证映射**：板块1/板块4 明确本单元对应哪类岗位任务、哪张（通用口径）证书技能点、哪个赛项评分项。
2. **课程思政融入**：在导入/总结或关键任务中设置思政点（工匠精神、科技报国、数据安全、职业规范等），自然不硬贴。
3. **企业资源/第三方评价**：资源清单与量规中纳入企业案例、真实生产标准、企业导师评价权重。
4. **数字化资源（板块10 必含）**：微课脚本、动画分镜、在线课程章节设计（见 [assets/microcourse_script.md](assets/microcourse_script.md) 等）。

## 批量多单元设计工作流（课程级）

当输入含有「进程周次 / 作品矩阵」且需产出整门课程的多个单元时，按以下顺序执行（避免周次撞车、保证一致性）：

1. **对齐命名体系**：先把整体设计「作品 N」⇄ 进程总览「视频 N」对齐成唯一映射表，标注平行方案（若有）。
2. **产出映射矩阵**：列出「周次 / 作品 / 单元主题 / 核心任务」骨架，确认无重复周次、无串行平行方案。
3. **逐周产出单元**：严格按周次顺序，每份采用同一套 11 板块标准模板（[assets/lesson_design_template.md](assets/lesson_design_template.md)），文件名与内部周次一致。
4. **末尾生成总览**：全部单元完成后，生成《单元设计总览/索引》（模板见 [assets/unit_overview_template.md](assets/unit_overview_template.md)），含全课程单元总表 + 逐周映射一致性矩阵 + 能力/岗课赛证/思政一致性说明。

> 单课设计可跳过此流程，直接输出一份 11 板块教案。

## 评价设计（教学评一体化）

- **过程性评价**：提示词/操作记录表、同伴互评、321 出门条、Gallery Walking
- **成果性评价**：4 级量规（维度对接教学目标 + 岗课赛证标准），见 [assets/rubric_template.md](assets/rubric_template.md)
- **终结性评价**：测试/实操考核/单元答辩
- **企业导师评价**：真实生产标准、企业师傅评分纳入成果性评价
- 成绩构成参考：过程性 30-40% / 成果性 40-50% / 终结性 20-30%

保留「五层激励体系」结构，但激励锚点切换到职教学生真正在意的：
**职业认同、工匠精神、课证融通、竞赛获奖、就业竞争力、技能增值**。

## 设计原则核查清单

### 整体一致性（铁律相关）
- [ ] 单元骨架来自整体设计的项目/任务/周次，未把课标模块单独成教学单元
- [ ] 平行方案（如有）共用相同周次、并列呈现，未串行排在不同周次
- [ ] 证书表述为通用口径（职业技能等级证书/行业认证/企业认证），无 特定证书体系 字样
- [ ] 两套命名体系已对齐，无周次撞车 / 重复文件
- [ ] 文件名周次 = 内部「对应周次」字段
- [ ] 单元目标源自课程整体设计（PGSD/课标），素养维度口径一致
- [ ] 岗课赛证对接点已明确（岗位/证书/赛项）
- [ ] 课程思政主线在本单元有具体融入点

### 目标与规范
- [ ] 教学目标使用布卢姆行为动词（未用「了解/理解/掌握」等心理动词）
- [ ] 三维目标各 2-4 条，素养维度对接 PGSD
- [ ] 核心任务为真实/典型工作任务，非课堂练习题

### 课堂规范
- [ ] 符合 11 板块结构
- [ ] 六环节齐全，合计 180 分钟（或 90 分钟）
- [ ] 第 5 列每环节写设计意图；含岗课赛证映射与思政融入
- [ ] 探究新知有具体示证（示范/引导发现）；应用新知学生有动手操练
- [ ] 合作学习法仅用于重难点，全程最多 1-2 个
- [ ] 教案正文未出现内部术语（Show-Q/Show-C/DOid/DOex/首要教学原理——理论框架 reference 可用学术名，教案「设计意图」列用大白话）

### 资源与评价
- [ ] 生成了配套资源（结合具体教学内容，非空模板）
- [ ] 板块10 含微课脚本 + 动画分镜 + 在线课程章节
- [ ] 评价量规维度对接教学目标与岗课赛证标准
- [ ] 差异化支持具体可操作

## 术语使用规则

- 可出现在教案中：PBL、UbD、BOtPPPS 及六环节名称、岗课赛证、理实一体

## 总结

本技能是**通用型职教课程单元设计引擎**：在已有课程整体设计（推荐 PGSD 产出）+ 进程周次之上，用 BOtPPPS + 理实一体模型，把整体目标拆解为可执行的周单元（180min，兼容 90min）11 板块教案，强制落实岗课赛证融通、课程思政、企业导师评价与数字化资源生成，并支持批量多单元与《单元设计总览/索引》产出。
**与课程无关，输入驱动；五条铁律不可违反。**
核心原则：**目标可测、评价先行、学生中心、真实任务、岗课赛证融通、教学评一体**。
