# 单元表现性任务设计模板（GRASPS · 高职）

> 用于把"单元任务"写成真实/典型工作任务。对接岗课赛证，让学生像准员工一样产出可用成果。

## GRASPS 六要素

### G - Goal（目标）
| 项目 | 内容 |
|------|------|
| 任务要达成什么 | |
| 对应的单元教学目标 | |

### R - Role（角色）
| 项目 | 内容 |
|------|------|
| 学生扮演什么角色 | 如：XX 岗位实习生 / 项目组员 |
| 为什么选这个角色 | 贴合专业与职业情境 |

### A - Audience（受众）
| 项目 | 内容 |
|------|------|
| 成果给谁看 | 如：企业导师 / 客户 / 专业群 |
| 受众为什么在意 | |

### S - Situation（情境）
| 项目 | 内容 |
|------|------|
| 面临什么真实/典型工作任务情境 | |
| 约束条件 | 时间、成本、规范、标准等 |

### P - Performance（表现/产出）
| 项目 | 内容 |
|------|------|
| 要产出什么具体成果 | |
| 成果形式 | 报告/数字作品/实物/展演 |

### S - Standards（标准）
| 项目 | 内容 |
|------|------|
| 怎么评判好坏 | 含岗位/证书/赛项标准 |
| 对应评价量规维度 | |

## 情境任务描述

> 将 G/R/A/S/P/S 串成一段生动任务说明，让学生看完就明白：扮演谁、为谁、解决什么真实问题、产出什么、达什么标准。
