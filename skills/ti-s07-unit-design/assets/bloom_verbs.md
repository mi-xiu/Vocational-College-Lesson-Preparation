# 布卢姆行为动词参考表

## 使用说明

教学目标必须使用可观察、可测量的外显行为动词。格式：学生学完本项目后，能【行为动词】【学习对象】。

**禁止使用**："了解""理解""掌握""体会""知道""认识""领会"等描述内部心理过程的动词。

## 行为动词分类

### 记忆/回忆层次（知识目标）

| 行为动词 | 使用示例（AI课程） |
|---------|------------------|
| 说出 | 说出人工智能的三个核心概念 |
| 列举 | 列举生成式AI的典型应用场景 |
| 复述 | 复述提示词编写的基本公式 |
| 辨认 | 辨认不同AI工具的适用场景 |
| 匹配 | 匹配AI工具与其功能 |
| 标明 | 标明通知格式中的关键要素 |
| 排列 | 排列AI项目实施的步骤顺序 |

## 三维目标对应速查

| 目标维度 | 对应层次 | 条数要求 | 常用动词 |
|---------|---------|---------|---------|
| 知识目标（学习理解） | 记忆/回忆 + 理解 | 3-5条 | 说出、列举、解释、举例、比较、总结 |
| 能力目标（应用实践） | 应用 + 分析 | 3-5条 | 操作、使用、制作、撰写、分析、对比、检查 |
| 素养目标（迁移创新） | 评价 + 创造 | 3-5条 | 评价、判断、选择、设计、创建、规划、创作 |

> 注：单次课教学目标三维各2-4条，项目教学目标三维各3-5条
