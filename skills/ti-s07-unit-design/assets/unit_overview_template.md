> **用途**：批量多单元设计完成后，生成一份总览文档，串联全部单元、固化周次/作品映射、做一致性自检。详见 SKILL.md「批量多单元设计工作流」第4步。
> **填写纪律**：逐周映射表须与每份单元设计的文件名/内部「对应周次」严格一致；任何冲突在此暴露并修正。

## 三、能力 / 岗课赛证 / 思政 / 资源一致性说明

- **PGSD 四维覆盖**：确认 S/G/P/D 在单元目标中全程分布，无缺维。
- **课标模块定位**：确认所有单元骨架来自整体设计项目/任务/周次，课标模块（M1–M8）仅作能力参考，未单独成单元。
- **岗课赛证口径**：证书统一用「职业技能等级证书 / 行业认证 / 企业认证」通用表述，全课程无 特定证书体系 字样；岗位/赛项对接点逐单元明确。
- **课程思政**：逐单元有具体融入点，主线贯通。
- **数字资源**：每份单元含微课脚本 + 动画分镜 + 在线课程章节（板块10）；配套脚手架非空。
- **模板一致性**：全部单元采用同一 11 板块标准模板（[lesson_design_template.md](lesson_design_template.md)），文件名周次 = 内部声明。

## 四、使用与交付建议

- 本总览作为单元设计的「目录 + 一致性证书」，配合 N 份单元设计文件交付。
- 如需落到校历：另做「课时授课计划表 / 教学进度表」，把单元周次映射到具体日期与节次。
- 如需形成性评价留痕：另做「单元前测–后测纵向数据追踪表」。
