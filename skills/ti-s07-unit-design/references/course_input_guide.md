# 课程整体设计摄入指南（本技能的输入规范）

> 本技能**不负责**从零规划一门课。它假设"课程整体设计 + 进程周次"已经存在，本文档规定如何把整体设计转化为单元设计的输入，保证上下一致。**通用、课程无关**：只要提供某职教课程的整体设计与周次安排，即可产出该课程单元。

---

## 一、整体设计应包含哪些信息

单元设计至少需要从整体设计中提取以下 6 项：

| 序号 | 信息项 | 作用 | 若缺失 |
|------|--------|------|--------|
| 1 | 课程名称、所属专业/专业群 | 定位单元归属 | 必须追问 |
| 2 | 素养维度（如 PGSD：职业素养/通用能力/专业技能/发展能力） | 单元素养目标口径 | 必须追问 |
| 3 | 课程总目标（三维或 PGSD 维度） | 单元目标的来源 | 必须追问 |
| 4 | 模块/项目结构 | 单元在课程中的位置 | 必须追问 |
| 5 | 整体评价框架 | 单元评价占比与量规口径 | 有则沿用，无则按默认 |
| 6 | 课程思政主线 | 单元思政融入点 | 有则沿用，无则本单元自定 |

---

## 二、进程周次 / 作品矩阵（单元骨架的直接来源）

> **关键**：单元设计以「周次 / 作品（项目/任务）」为骨架（铁律1），因此必须拿到课程的进程周次安排。缺失时须追问，否则无法排布单元。

| 序号 | 信息项 | 作用 | 若缺失 |
|------|--------|------|--------|
| 7 | 进程周次 / 作品矩阵（第X–Y周 → 作品N） | 确定每个单元的周次与作品归属 | 必须追问 |
| 8 | 平行方案（如有） | 同一作品含按班级二选一的多个方案，须共用周次并列 | 标注并确认周次 |
| 9 | 命名对齐表（整体设计「作品N」⇄ 进程「视频N」） | 消除两套命名歧义，避免周次撞车 | 须先对齐再产出 |

**进程周次输入示例**：

```plaintext
【进程周次 / 作品矩阵】
第 1–2 周：作品1 XXX（入门）
第 3–4 周：作品2 XXX
第 5–6 周：作品3 XXX
第 7–8 周：作品4 XXX
第 9–10 周：作品5 XXX（含平行方案A / 方案B，按班级二选一）
第 11–14 周：作品6 XXX（综合）

【命名对齐表】（整体设计作品N ⇄ 进程视频N）
作品2 ⇄ 视频1 ｜ 作品3 ⇄ 视频2 ｜ 作品4 ⇄ 视频3 ｜ 作品6 ⇄ 视频4（综合）
```

## 三、与 PGSD 工作流的衔接

若整体设计由 `ti-s06-course-blueprint` 产出，直接读取其输出：

- **PGSD 能力模型** → 单元素养维度口径（职业素养/通用能力/专业技能/发展能力）
- **课程标准** → 课程目标、模块结构、评价框架（能力标准母本，仅作能力参考，**不单独成教学单元**）
- **课程整体设计** → 项目/任务、周次进程、作品矩阵（本技能的主输入与单元骨架来源）

映射关系：

| PGSD / 整体设计产出 | 本技能使用方式 |
|----------|--------------|
| 课程目标（PGSD 四维） | 拆解为单元三维目标（知识/能力/素养） |
| 项目/任务 + 周次进程 | 确定"单元的周次归属与作品骨架"（铁律1） |
| 评价量规（PGSD） | 单元量规维度与之对齐，补充岗课赛证维度 |
| 课程思政设计 | 本单元思政融入点来源 |

> 注意：课程标准中的**模块（M1–M8）仅作能力参考**，不对应单独教学单元；教学单元须由整体设计的项目/任务/周次派生。

## 四、岗课赛证对接信息的提取

单元设计独有的输入项是"岗课赛证对接点"，从以下来源提取（证书用**通用口径**，禁 特定证书体系 字样）：

| 来源 | 提取内容 |
|------|---------|
| 专业教学标准 / 岗位职业标准 | 本单元对应的典型工作任务、岗位能力要求 |
| 职业技能等级证书 / 行业认证 / 企业认证标准 | 本单元覆盖的技能点、考核要求 |
| 职业技能大赛赛项规程 | 本单元对应的赛项评分项、操作规范 |
| 企业真实案例/生产标准 | 真实情境、验收口径、企业导师评价项 |

> 若用户未提供岗课赛证信息，技能应提示"建议补充对接点以提升职教适配度"，但可在单元中预留对接列，待后续补全。

---

## 五、平行方案处理规则（铁律2）

同一作品含多个平行方案（如方案 A 直播 / 方案 B 短视频综合）时：

- 两方案**共用相同周次**，在该周次下**各出一份单元设计**（文件名标注 方案A / 方案B）；
- **不得**把方案 A 排在前两周、方案 B 排在后两周（串行）；
- 单元内须显式标注「与方案X平行 · 班级二选一」，并在基本信息/骨架声明中写明。

## 七、一致性校验（单元设计完成后回查）

单元设计产出后，反向核对：

- [ ] 单元三维目标 ⊆ 课程总目标（不超纲、不遗漏关键项）
- [ ] 素养维度口径与整体设计一致（如均为 PGSD）
- [ ] 单元骨架来自整体设计项目/任务/周次，未把课标模块单独成单元
- [ ] 平行方案（如有）共用周次、并列呈现，未串行
- [ ] 证书表述为通用口径，无 特定证书体系 字样
- [ ] 单元评价占比之和落在整体评价框架内
- [ ] 单元量规维度与整体量规对齐
- [ ] 岗课赛证对接点与专业教学标准/证书/赛项一致
- [ ] 文件名周次 = 内部「对应周次」字段
