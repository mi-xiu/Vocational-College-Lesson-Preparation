# 教学方法与工具库

> 融合Li≈Sir教育框架的实用工具与中职AI课程教学方法

## 一、课堂教学范式

### "自主·生动·高效"课堂模式（融合Li≈Sir）

| 特征 | 要求 | 量化指标 |
|------|------|---------|
| 自主 | 保障学生连续、不受干扰的深度活动时间 | 教师讲授≤15分钟，学生活动≥15分钟 |
| 生动 | 真实情境导入、游戏化活动、小组合作 | 学生发言≥10人次/课 |
| 高效 | 每堂课有清晰的"一句式当堂目标"，嵌入即时反馈 | 教学评同步推进 |

### 项目化七环节（Li≈Sir微观操作流程）

> 适用于简化版的单课时设计，与BOtPPPS互为补充

| 环节 | 时间 | 内容要点 |
|------|------|---------|
| 一句式当堂目标 | 1min | 清晰陈述本节课要达成的具体产出 |
| 情境导入 | 2-3min | 用真实问题、故事或范例迅速将学生"拉入"任务情境 |
| 迷你讲授 | 7-15min | 针对当前任务所需的必备知识，短时、精准讲授 |
| 当堂产出与分工 | 2-3min | 明确本节课要完成的具体产品片段，进行小组角色与任务分工 |
| 高质量学生活动 | ≥15min | 给予学生充分且不受干扰的操作、探究、协作时间 |
| 形成性检查 | 3-5min | 通过巡视、抽样、简短分享等方式，进行过程性评估 |
| 总结展示与下一步 | 3-5min | 展示阶段性成果，总结学习要点，明确后续任务 |

## 二、学习鹰架工具

### 鹰架设计原则（融合Li≈Sir理念）

1. **任务分解**：将大任务拆解为可管理的子任务
2. **步骤指引**：提供清晰的操作流程
3. **学习鹰架**：在关键节点提供支持工具
4. **多元成果**：允许不同形式的成果呈现
5. **分享展示**：设计公开发布环节

## 三、形成性评价工具

### 321出门条

学生在课堂结束时快速填写：

| 项目 | 内容 |
|------|------|
| 3 | 今天学到的3个要点 |
| 2 | 还有疑问的2个问题 |
| 1 | 最想记住的1个想法 |

**用途**：快速收集学习反馈、诊断理解程度、调整后续教学

### PMIQ反思表

| 字母 | 含义 | 反思问题 |
|------|------|---------|
| P | Plus（优点） | 本次学习/活动中做得好的地方是？ |
| M | Minus（不足） | 可以改进的地方是？ |
| I | Interesting（有趣） | 最有趣/意外的发现是？ |
| Q | Question（问题） | 还想进一步了解的问题是？ |

### Gallery Walking（画廊漫步）

- 各组将作品/方案展示在桌面或墙上
- 其他组巡回观看，用便利贴写1条优点+1条建议
- 所有组都能获得多方反馈
- 培养审美评价能力

### 同伴互评表

基于评价量规的简化版，聚焦本次课的核心学习内容：
- 互评维度与量规对应
- 使用"达标/待改进"二分法简化操作
- 要求写出具体优点和改进建议

## 六、差异化支持策略

### 基础较弱学生支持

| 策略 | 具体做法 |
|------|---------|
| 脚手架支持 | 提供填空式提示词模板、操作步骤卡 |
| 降低难度 | 缩小任务范围，先完成基础部分 |
| 同伴互助 | A带C，一对一旁观学习 |
| 即时反馈 | 每完成一小步就确认，不让错误积累 |
| 进步认可 | 设置"进步奖"，关注进步而非绝对水平 |

### 学有余力学生拓展

| 策略 | 具体做法 |
|------|---------|
| 挑战任务 | 尝试用不同AI工具对比效果、分析差异原因 |
| 创意拓展 | 在基础要求上增加创意元素（如多种风格海报） |
| 技术指导 | 担任"小老师"指导其他同学（也能加深自己的理解） |
| 深度反思 | 引导思考AI的局限性和伦理问题 |
| 跨项目迁移 | 将所学方法迁移到其他场景 |
