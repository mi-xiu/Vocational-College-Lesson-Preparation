# 高职课程标准与岗课赛证参考

> 本技能不内置中职《AI 通识课教学指南》。高职课程开发依据以下标准口径；具体课程的素养维度、证书/赛项由用户从整体设计中提供。

## 一、高职课程开发依据（通用口径）

| 依据 | 用途 |
|------|------|
| 教育部《职业教育专业教学标准》 | 确定典型工作任务、岗位能力要求 |
| 职业技能等级证书标准 | 单元技能点、考核要求对接 |
| 全国/全省职业技能大赛赛项规程 | 操作规范、评分项对接 |
| 专业群人才培养方案 | 课程定位、前后续课程关系 |
| 课程思政建设指南 | 思政主线与融入点 |

## 二、素养维度推荐口径

高职通用素养维度（与 PGSD 模型一致，推荐默认使用）：

| 维度 | 内涵 | 单元目标落点 |
|------|------|-------------|
| 职业素养（P） | 职业道德、规范意识、安全、协作 | 思政/规范类目标 |
| 通用能力（G） | 沟通、信息、学习、解决问题 | 跨课程可迁移目标 |
| 专业技能（S） | 岗位核心操作与方案能力 | 单元核心能力目标 |
| 发展能力（D） | 创新、迁移、终身发展 | 拓展/挑战目标 |

> 若课程整体设计已定义素养维度，以其为准，本技能不做覆盖。

## 三、岗课赛证融通设计要点

| 融通项 | 单元设计中如何体现 |
|--------|------------------|
| 岗（岗位） | 单元任务 = 典型工作任务；验收 = 岗位标准 |
| 课（课程） | 单元目标 ⊆ 课程目标；评价占比落在整体框架 |
| 赛（赛项） | 单元操作规范/评分项对接赛项规程 |
| 证（证书） | 单元技能点覆盖证书考核要求（证书统一用通用口径：职业技能等级证书 / 行业认证 / 企业认证） |

> **证书口径铁律（铁律3）**：严禁出现「特定证书体系 证书 / 特定证书体系 技能点 / 特定证书体系 过程证据」等 特定证书体系 相关字样。岗课赛证之「证」维不特指 特定证书体系，统一用上述通用表述。

## 四、课程思政融入建议

高职思政主线常见方向（结合专业自然融入，不硬贴）：

- 工匠精神、精益求精、标准意识
- 科技报国、服务区域产业
- 数据安全、隐私保护、知识产权、学术诚信
- 职业规范、安全生产、责任担当
- 团队协作、沟通表达、工匠精神与劳模精神

> 思政融入点写在板块4「设计意图」列与总结环节，避免额外堆砌。

## 五、评价框架默认参考

| 评价类型 | 占比 | 工具 |
|---------|------|------|
| 过程性评价 | 30-40% | 操作记录、同伴互评、321 出门条 |
| 成果性评价 | 40-50% | 4 级量规（对接岗课赛证） |
| 终结性评价 | 20-30% | 测试/实操/单元答辩 |

> 企业导师评价可纳入成果性评价权重（如 10-20%）。
