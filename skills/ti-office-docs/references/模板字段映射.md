# 模板字段 ↔ 项目内容 映射表（模板导出专家操作手册）

> 适用范围：默认三件套模板（课程标准 / 授课计划 / 单元教案）+ 当前项目《AI短剧编剧》。
> 用法：导出某文档前，逐行对照"项目来源"抽取/重组内容；标【需补】的向用户索取；标【需整合】的由专家从多源合成。
> 模板为"八章式"骨架，本项目母本为"十节式"，**须重映射，勿直接复制**。

## 四、待用户/项目补充的总清单（生成前必须闭环）

1. **身份类**：任课教师姓名、具体授课班级、课程标准版本号、课程代码（教务分配）、编制日期。
2. **授课计划 T0**：讲课/练习/实验/复习/考试/测验/实习/其它 的学时拆分（建议 讲课4/练习12/其余0）。
3. **授课计划 T1**：8 个单元各自的"课外作业"一句话。
4. **课程标准 T3**：评价样表配分（合计=100，建议 知识20/技能50/职业素养30，对齐过程60/终结40）。
5. **单元教案**：每份的授课地点、教师姓名、日期；确认"教学准备/反思拓展"节是否齐备。
6. **模板规范化门**：默认三件套已 optimize 抽 spec；若用户后续替换自定义模板，须先跑规范化门再生成。

> 以上闭环后，由 `course.yaml`（身份+共享骨架）统一驱动 `build_course.py` 一键渲染三件套并逐份 verify。
