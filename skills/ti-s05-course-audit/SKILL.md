# S05 课程现状梳理（Course Status Audit）

## 定位

专家团**第二阶段首步（④课程现状梳理专家）**的核心引擎。与 S01–S04「从零建课」正向流程不同，本技能服务**「已有课程存量盘点 + 改造前置」**：在动手写/改课标、整体设计之前，先把这门课的"家底"摸清楚——教材、学生、课时、项目来源、课程现状、模板口径，六路并进，给下游（③课标复用判定、⑤整体设计、⑥⑦备课）一份可信的现状基线。

> 这是一个**诊断/审计**角色，不是**生成**角色。它产出"现状事实 + 复用判定 + 问题清单 + 模板遵照清单"，不动手写正式课标/整体设计——那是 ③⑤ 的事。

## 硬约束（全团红线，本技能 MUST 遵守）

1. **PGSD 编号统一**：若引用能力点，沿用全局 PGSD 四维（P方法/G通用/S技能/D发展）与既有编号，不另起一套。
2. **两层分离**：教材/留存资料评估只判断"能不能用、怎么用"，不得把"现状课标"直接当成新"课程标准"——新课标由 ③ 重做，本技能只给复用判定。
3. **命名纪律**：输出文件统一 `课程现状梳理报告.md`；引用既有文件时用其原路径，不改名。
4. **禁 特定证书体系**：证书口径统一"职业技能等级证书 / 行业认证 / 企业认证"，不出现"特定证书体系 证书"表述。
5. **量规二值 + 标★**：本技能对"留存资料可复用性""模板符合性"的判定用 `✔/✘ + 标★` 二值判据 + 对应闸门，不套通用 4 级量表。
6. **课时确认铁律（S05 专属·最高优先级）**：**进入 S06 整体设计之前，MUST 用 AskUserQuestion 向客户（用户）显式确认「每周课时数 × 总周数」（二者乘积 = 总学时）。即使人才培养方案 / 课表已写明周学时与总周次，也 MUST 由客户二次明确确认，不得直接用方案值代过。** 未获客户确认，不得进入 Step 5 之后的 S06 路由。确认结果写入本报告课时安排核对节，并作为 S06 周次进程的唯一事实依据。

## 六路调研清单（用户指定范围全覆盖）

| # | 调研项 | 必答问题 | 复用资产 |
|---|---|---|---|
| 1 | **教材** | 现用教材是哪几本？主编/版次/出版社？与课标能力点契合度？需补/换哪些？ | — |
| 2 | **学生情况** | 授课对象起点能力/动机/数字素养/班情差异？ | `ti-s05-learner-profile` 学情法（Step1–4） |
| 3 | **课时安排** | 人才培养方案/课表给的学时学分？周学时？是否含实训周？与新课设冲突点？ | L1-1 人才培养方案（方案Word+课表Excel） |
| 4 | **教学项目来源** | 校企真实项目 / 往届学生作品 / 可复用载体有哪些？版权与可用度？ | `ti-s02-resource-collector` 扫描法（Step3 只读扫描） |
| 5 | **课程现状** | 人才培养方案怎么定位本课（前导/后继）？留存资料（课标/教案/作业/PPT/授课日志）哪些可复用、哪些需重写？希望解决的主要问题？ | L1-1 / L2-1 / L2-2 / L2-3 / L2-4 / L3-B1~B4 |
| 6 | **模板符合性** | 本课须遵照哪些校级/院级模板？与 L0–L3 编码如何对应？缺失哪些？ | `Ti_课程模板库整理` L0–L3 编码 + Phase 0 模板 |

## 工作流

### Step 1 索取现状资料（只读）
- 用 AskUserQuestion 或清单请用户上传/指路径：人才培养方案、现用教材信息、往届留存资料（课标/教案/作业/PPT/授课日志）、拟遵照模板、课时/课表。
- **只读原则**：对 tdrive / 本地文件只 Glob/Read 扫描，不移动/改名/删除（安全红线，参照 `ti-s02-resource-collector` Step3）。

### Step 2 教材适配性评估
- 列出教材，对照（待建/已有的）能力图谱或岗位面向，做契合度评估表（参考 `references/课程现状诊断提纲.md` 表 B）。
- 结论：✅ 直接复用 / ⚠️ 部分适配需补充 / ✘ 建议更换。

### Step 3 学情诊断
- **调用 `ti-s05-learner-profile`** 的 Step1–4（起点能力/特征画像/班情差异），产出本节"学生情况"小节，作为 ⑤ 整体设计难度与 ⑥ 单元分层依据。

### Step 4 课时核对
- 从 L1-1 人才培养方案 + 课表抽取本课程学时学分、周学时、总周次、是否含实训，与用户新课设想对比，标冲突点（如总学时不足、周次错位）。
- ⚠️ **课时确认铁律（见硬约束 #6）**：抽取到的方案值**仅作草稿**。**MUST 调用 AskUserQuestion 向客户二次确认「每周课时 × 总周数」**——即使方案已写明，也须客户明确说"确认 / 就按这个"。确认前禁止进入 S06；确认值写入 §5.1 课时核对表并标「客户已确认」，作为 S06 周次进程唯一依据。

### Step 5 教学项目来源盘点
- 盘点校企项目、往届作品、可复用载体，做"来源–可用度–版权"三列判定（参考 `references/课程现状诊断提纲.md` 表 C）。
- 区分"从零找新载体"（⑤ 的工作）与"既有可复用载体"（本课可直接用）。

### Step 6 课程现状审计 + 留存资料判定
- 解析人才培养方案对本课的定位（前导/后继/课程性质）。
- 对每份留存资料做**二值复用判定**（✔/✘ + 标★）：✅ 原样复用 / ⚠️ 改写复用 / ✘ 重写。
  - 判定闸门见 `references/模板符合性检查表.md`（复用闸门：内容是否对齐新课能力点、格式是否符合 L 编码、是否含 特定证书体系 等违禁表述）。
- 提炼用户"希望解决的主要问题"（3–6 条，按优先级排序）。

### Step 7 模板符合性检查
- 对照 `Ti_课程模板库整理` L0–L3 编码 + Phase 0 模板，逐项核对本课须遵照模板（见 `references/模板符合性检查表.md`），输出**模板遵照清单**（必用模板 + 可选模板 + 缺失待补）。

### Step 8 成稿《课程现状梳理报告》
- 输出 `课程现状梳理报告.md`，结构见下方"输出物"。

## 输出物

`课程现状梳理报告.md`（落点建议：`03_学情与整体设计/S05_课程现状梳理/`），含：

1. **课程基本信息**：课程名/专业/性质/在培养方案位置（前导/后继）。
2. **教材适配评估表**（含 ✔/✘ + 标★ 结论）。
3. **学生情况**（学情诊断摘要，引用 `ti-s05-learner-profile` 产出）。
4. **课时安排核对**（培养方案学时 vs 新课设想，冲突标红）。
5. **教学项目来源清单**（来源–可用度–版权）。
6. **课程现状审计**：人才培养方案定位 + **留存资料复用判定表**（✔/✘ + 标★ + 复用方式）。
7. **主要问题清单**（3–6 条，优先级排序）。
8. **模板遵照清单**（必用/可选/缺失，挂 L 编码）。

> 下游回灌：③（旧课标可复用判定）→ ⑤（项目来源/课时/模板）→ ⑥⑦（模板/PPT/授课日志规范）。

## 与相邻技能

- **上游**：①岗位调研（培养方案位置）、用户提供的现状资料。
- **下游**：③课程标准（复用判定）、⑤整体设计（项目来源/课时/模板）、⑥单元设计、⑦备课素材（PPT/授课日志规范）。
- **编排**：由 `ti-s01-s09-course-build` 的"④课程现状梳理专家"路由触发，位于第二阶段首步。
