# S06 课程整体设计（项目化落地）

## 定位
专家团**⑤整体设计专家**：合并 S06（课程整体设计）+ S08（授课计划）两步，一专家产出。
回答"怎么教"。基于 S04 课标能力标准做项目化落地实施方案，绑定具体项目/作品/周次/任务；整体设计定稿后，**直接派生校历级授课计划文件**（S08 由本专家一并产出，不再独立成步）。

## 两层纪律
- 整体设计 ≠ 课标。课标定能力，本文件定项目任务顺序与难度。
- 文件名 `<课程名>-课程整体设计（<项目版>）.md`。

## 硬约束
- 项目与任务从易到难；模块×作品调用矩阵齐备。
- 与 S20 L2-2 学校模板对齐（课程概况 / 课程作用 / 学生分析 / 课程目标 O+KSA / 教学方法 BOPPPS 六环节 / 任务情境）。

## 工作流
### Step 1–5（复用 S02 任务分析成果）
- 抽取课标能力骨架 → 典型任务 → 项目载体筛选 → 任务拆解 → 能力图谱引用。

### Step 6 产出整体设计文件
- 九章：课程概况 / 课程作用 / 学生分析 / 课程目标(O+KSA) / 课程内容(模块) / 学习任务(情境) / 学业评价 / 教学方法(BOPPPS+九法) / 进程与课时。
- 参照 references/overall-design-template.md。

### Step 7–8 归档与提示下游
- 产出 `课程整体设计-<课程名>（<项目版>）.md`。

### Step 9 派生授课计划（S08，合并本步）
- 由 `<N>周进程总览` 派生 `授课计划-<课程名>.md`（2 表含唯一"**思政要素**"列）。
- 可调用 `ti-s08-teaching-plan` 辅助：排定周次/章节/重难点/思政要素/课外作业。
- 落点：`08_授课计划/授课计划-<课程名>.md`。

## 输出物
- `课程整体设计-<课程名>（<项目版>）.md`
- `授课计划-<课程名>.md`

## 与相邻技能
- 上游：S04；**本专家合并吸收 S08（原 ti-s08-teaching-plan 授课计划）**。
- 下游：S07（项目/任务/周次→单元骨架）、S09/⑦（资源包组织）。
