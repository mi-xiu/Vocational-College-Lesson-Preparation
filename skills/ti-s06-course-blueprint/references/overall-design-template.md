## 一、设计理念与逻辑
- 核心逻辑：1 个贯穿式项目（<项目载体>）分三阶段，难度递进 = 技能点"初级 → 中级 → 高级"进阶。
- 三阶段：P1 入门立项（教师支架式）→ P2 长期主线（日常运营 + 变现，达中级=及格）→ P3 冲刺（高质量提升，达高级）。

## 三、各阶段详述

### P1 入门立项（第 1–2 周）
- 目标：教师给案例/策划，学生执行走通全流程，达初级能力。
- 工作内容：研究官方号风格 → 定账号定位 → 选题→脚本→拍摄→剪辑→发布→复盘 全流程一遍。
- 技能点达成（初级）：<列 S/G/P/D 初级档>。
- 产出：① 首条视频；② 账号定位表。
- 考核：过程性，对应"初级"（未达课程及格线）。

### P2 长期主线（第 3–<n> 周）
- 目标：以账号定位为基准日常更新贯穿全学期，<含变现：挂 POI + 团购链接卖门票/套票>，达中级=课程及格。
- 4 个递进作品（难度随周升，按数据/反馈/质量三维度评价）：
  | 作品 | 周次 | 复杂度 | 创作要求 | 评价三维度 |
  |---|---|---|---|---|
  | 作品1 | 3–4 | 简单 | <单场景口播/手机拍摄/粗剪> | 数据/反馈/质量 |
  | 作品2 | 5–6 | 较复杂 | <加运镜灯光/精剪调色> | 数据/反馈/质量 |
  | 作品3 | 7–8 | 更复杂 | <多场景+出镜/包装体系> | 数据/反馈/质量 |
  | 作品4 | 9–<n> | 复杂 | <综合/AI 工作流/冲官方号> | 数据/反馈/质量 |
- 出镜要求：<必须 / 推荐 / 可选>。
- 技能点达成（中级）：<列 S/G/P/D 中级档>。
- 产出：① 账号作品集；② 周/月数据报告与复盘。
- 考核：过程性 + 数据复盘，对应"中级"（课程及格核心依据）。

### P3 冲刺（第 <n–2>–<n> 周，叠 P2）
- 目标：在 P2 不中断下，集中打造高质量爆款（冲粉丝/点赞/播放），达高级。
- 核心：以策划+运营为主的综合能力项目；教学主轴=<深度人文等>，学生创作更自由。
- 工作内容：爆款选题主导 → 账号运营 → 数据复盘 → 变现转化，制作服务于策划运营主线。
- 技能点达成（高级）：<列 S/G/P/D 高级档>。
- 比赛参考：<若仅作质量参考，写明对标哪些规格但不提交；若真参赛，写清赛事/赛道/硬性规格>。
- 产出：① 高质量爆款 1–2 条；② 作品集终稿 + 复盘报告。
- 考核：终结性（作品/答辩），对应"高级"（优秀目标）。

## 填写要点

- **周次/学时**必须与实际教学计划一致；P2 与 P3 并行的周次要在总表与详述都标注清楚。
- **咬合矩阵**是评审重点：证明每个模块在三个阶段都被覆盖、且能力点有主投阶段。
- **考核占比**递进对应 初/中/高；中级占比最大（它是及格线主战场）。
- **比赛口径**二选一，写清；选"仅作质量参考"就不要出现"提交/校赛选拔/赛果"等措辞。
