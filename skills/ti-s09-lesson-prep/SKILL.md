# S09 课堂备课包与资源组织

## 定位
专家团**⑦备课素材专家**：把 S07 单元设计 + S08 授课计划，落成"上课直接能用"的资源包，资源按 R1–R10 编码。
资源缺口补采时，**复用 `ti-s02-resource-collector` 的方法论**（网络多渠道搜集 + 本地只读扫描 + 按能力点结构化 + 合并去重 + 缺口分析），本专家不重复造轮子。

## R1–R10 编码体系
- R1 学习材料 / R2 技术工具 / R3 评价工具 / R4 支架工具 / R5 企业资源 / R6 微课 / R7 动画 / R8 在线课程 / R9 题库 / R10 反思互评。

## 硬约束
- 每个备课包按周组织 10 类子目录（00说明/01工作页/02考题/03量规/04学材/05讲稿/06PPT/07动画/08微课/09设备/10拓展）。
- 须生成 `资源R编码索引.md`（用 gen_resource_r_index 脚本或手动）。

## 工作流
### Step 1 建周包骨架
- 按 S08 周次建 `备课包_第N周_...` 目录与 10 子目录。

### Step 2 填资源并对齐 R 编码
- 各资源归入 R1–R10，写索引。
- 若发现能力点缺资源支撑，调用 `ti-s02-resource-collector` 方法论做缺口补采（网络搜集 + 本地只读扫描）。

### Step 3 成稿与校验
- 产出各周 `资源R编码索引.md`；用 `check_s20_integrity.py` 校验。

## 输出物
- `05_课堂备课包/备课包_第N周_.../` 全套

## 与相邻技能
- 上游：S07/S08；编排收尾由 `ti-s01-s09-course-build` 的 S20 对齐环节接管。

## 参照
- S20 配套资料 / gen_resource_r_index.py（在编排 skill scripts 中）
- `ti-s02-resource-collector`（资源缺口补采方法论，Step2 调用）
