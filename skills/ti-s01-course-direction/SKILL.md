# S01 课程方向确认与就业调研

## 定位
九步法第一步，专家团**①岗位调研专家**（对外口径：岗位调研）。在动手写课标/整体设计之前，先确认课程**为什么存在、面向谁、毕业生去哪、对应哪些岗位**。本步只做"方向与就业画像"，不写课标正文。

> 专家团对外称「岗位调研专家」；技能内部名 `ti-s01-course-direction` 与产出物 `S01_方向确认与就业调研纪要.md` 保持不变，仅对外沟通改用"岗位调研"口径。

## 硬约束
- 不出现"特定证书体系"表述；证书对接保留为"职业技能等级证书 / 行业认证 / 企业认证"通用口径。
- 就业调研结论须可追溯（来源 / 时间 / 样本），禁止凭空编造岗位。
- 课程名/学时锁定以项目既有决策为准（以课标母本为唯一基准；培养方案改名时作别名/普通班并存，不二选一）。

## 工作流
### Step 1 确认课程方向
- 与用户确认：课程名称、所属专业、课程性质（公共 / 专业基础 / 核心 / 拓展）、开课学期、学时学分。
- 明确本课程在人才培养方案中的位置（前导 / 后继课）。

### Step 2 就业情况调研（宏观 + 方向专项）
- 宏观：用 WebSearch 查"XX 专业 就业方向 岗位"，整理 3–5 个主流就业方向。
- 专项：锁定本课程直接对应的岗位群（如短视频→短视频运营 / 编导 / 剪辑 / 直播）。

### Step 3 区域产业对接调研
- 查学校所在区域相关产业链 / 产业园 / 头部企业，标注可合作企业与真实项目载体。

### Step 4 证书调研（课证融通）
- 联网核对相关职业技能等级证书 / 行业认证，记录证书名称与能力要求。

### Step 5 竞赛标准联网核对（赛教融合）
- 查相关赛项（如职业院校技能大赛融媒体 / 短视频赛项），记录评分维度用于课程目标对齐。

### Step 6 数据可视化与纪要成稿
- 将岗位 / 证书 / 赛项整理成表，产出《S01 方向确认与就业调研纪要》。

## 输出物
- `S01_方向确认与就业调研纪要.md`：课程定位表、就业方向清单、区域产业对接、证书/赛项对照、结论与对下游（S03/S04）的建议。

## 与相邻技能
- 下游：S03 能力图谱（用岗位群拆 PGSD）、S04 课程标准（用定位写课程定位章）。
- 编排：由 `ti-s01-s09-course-build` 路由触发；Phase 0 模板索取在本步触发前完成。
