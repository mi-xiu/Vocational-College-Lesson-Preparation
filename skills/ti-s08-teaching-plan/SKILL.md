# S08 授课计划编制

## 定位
把 S06 整体设计的进程总览，展开成"这学期每周上什么"的校历级计划。

## 硬约束
- 必须含 S20 L2-4 模板独有的"思政要素"列（全库唯一）。
- 周次/课时与整体设计进程表一致；纯作品考核，不排笔试。

## 工作流
### Step 1 抽取进程总览
- 从 S06 取周次进程（如 14 周进程总览）。

### Step 2 填两表
- 表1 教学时数按学期分配（总学时 / 周学时 / 理论+实践）。
- 表2 计划表：授课顺序 / 周次 / 章节内容提要 / 教学课时 / 重点难点·思政要素 / 课外作业。

### Step 3 成稿
- 产出 `授课计划-<课程名>.md`。

## 输出物
- `授课计划-<课程名>.md`

## 与相邻技能
- 上游：S06；下游：S07（逐周对应单元）、S09（资源包按周组织）。
