# S03 PGSD 能力图谱与技能点

## 定位
专家团**②能力图谱专家**：合并 S02（典型工作任务分析）+ S03（PGSD 能力图谱）两步，一专家产出。
先把岗位真实工作任务拆成典型工作任务（TW 4–8，含三层结构与项目载体筛选），再把典型任务翻译成"学生该具备什么能力"——PGSD 四维（P方法/G通用/S技能/D发展），落到能力点。

## 硬约束
- PGSD 四维：S技能(主干)、G通用、P方法、D发展；不混用学校 KSA 三维（维度映射见 PGSD↔KSA 映射表）。
- 能力点须可观测、可考评；标注布鲁姆层级与难度。
- 禁用"特定证书体系"。

## 工作流
### Step 0 典型工作任务分析（S02，合并本步）
- 从 S01 岗位群提取 4–8 个典型工作任务（TW）；用三层结构（工作过程→任务→环节）拆解；筛选真实项目载体。
- 可调用 `ti-s02-task-resource` 辅助：产业/岗位调研 → TW 提炼 → 三层拆解 → 项目载体筛选。
- 产出 `S02_典型工作任务分析.md`（含案例台账思路）。

### Step 1 抽取课标/任务骨架
- 从 S01 定位 + Step0 的 TW，确定能力覆盖边界。

### Step 2 四维拆解
- 每个 TW 拆成 P/G/S/D 四类能力，写成能力条目。

### Step 3 能力点级细化
- 每条能力拆 1–N 个能力点，标"可观测行为 + 层级 + 难度"。
- 参照 references/pgsd-model.md。

### Step 4 成稿
- 产出 `S02_典型工作任务分析.md` + `S03_PGSD能力图谱（详细版）.md`；可选派生《PGSD→学校图谱扩展映射表》(18 列，供填 S20 L2-0)。

## 输出物
- `S02_典型工作任务分析.md`
- `S03_PGSD能力图谱（详细版）.md`

## 与相邻技能
- 上游：S01（岗位调研）；**本专家合并吸收 S02（原 ti-s02-task-resource 典型任务分析）**。
- 下游：S04（能力→课标目标）、S06（能力→模块/项目载体）、S07（技能点→单元目标）。
