# PGSD 能力模型详解

PGSD 是高职课程常用的四维能力框架，用于把"岗位要求"翻译成"可培养、可考核的能力标准"。

## 四维定义与典型指标

### P 职业素养（Professional Ethos）
软性底色，难以速成但可养成。典型指标：
- P1 职业道德与责任心（守时、保密、版权意识）
- P2 规范意识（遵守行业规范、平台规则、生产安全）
- P3 团队协作（跨角色沟通、接受反馈、分工配合）
- P4 职业形象与沟通礼仪（出镜 / 客户对接场景）

### G 通用能力（Generic Competence）
跨岗位可迁移。典型指标：
- G1 信息获取与甄别（检索、信源判断）
- G2 表达与沟通（书面、口头、脚本化表达）
- G3 自主学习（跟新工具、新平台规则）
- G4 创新思维（选题、创意、差异化）
- G5 数字化工具（Office / 协作 / 基础数据）

### S 专业技能（Specialty Skill）
岗位核心硬技能，按方向编号。示例：
- S1 脚本策划（选题、文案、分镜、节奏）
- S2 拍摄（构图、光线、运镜、收音）
- S3 剪辑（Pr / 剪映、调色、字幕、包装）
- S4 运营投放（选题排期、平台规则、投流、涨粉）
- S5 数据分析（完播率、转化、复盘优化）
- S6 出镜 / 主播（表达、控场、互动）

### D 发展能力（Developmental）
可持续与抗风险。典型指标：
- D1 适应变化（平台算法 / AI 工具迭代）
- D2 转岗 / 复合（运营 → 编导、剪辑 → 导演）
- D3 终身学习（证书、进阶学习路径）
- D4 数字素养与 AI 应用（用生成式 AI 提效）

## 分级标准（对应 合格 / 良好 / 优秀）

为每个 S 指标写三档可观测行为：
- **初级（合格）**：在指导下完成基础操作，产出可用但需修改。
- **中级（良好）**：独立完成任务，质量稳定，能小范围优化。
- **高级（优秀）**：主导复杂任务，能设计流程 / 带人 / 创新并复盘。

## 能力目标表述范式

课标"能力目标"建议分四类写，每类 2–4 条，使用"能 + 具体行为 + 产出"句式：
- **专业能力**：能完成……（对应 S 硬技能）
- **方法能力**：能运用……方法解决……（对应 G）
- **社会能力**：能在团队中……（对应 P）
- **发展能力**：能适应……并规划……（对应 D）
