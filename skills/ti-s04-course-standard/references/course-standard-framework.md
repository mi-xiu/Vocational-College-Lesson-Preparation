# 高职课程标准框架与评审要点

> 术语纪律：**课程标准 ≠ 课程整体设计**。课程标准是能力标准母本（培养什么能力），不绑定项目/作品/周次；课程整体设计是项目化落地方案（怎么教），绑定项目载体与周次进程。文件名分别为 `课程标准-<课程名>.md` 与 `课程整体设计-<课程名>（<项目版>）.md`，不得混用或互相代指。

## 课程标准九大字段

1. **课程基本信息**：课程代码、名称、性质、学分、学时（含理论/实践拆分）、适用专业、先修后续。
2. **课程定位**：
   - 区域对接：点名学校所在地的具体产业带 / 集聚区（来自区域产业调研），指明实训与就业腹地；
   - 岗课赛证四线：**岗**（岗位矩阵）、**课**（模块骨架）、**赛**（联网核对后的赛事单元/赛道）、**证**（通用证书体系 + 职业技能等级证书 + 行业认证 + 企业认证，统一用通用证书口径，不特指任何特定证书制度）；
   - 在课程体系中的角色（承上启下）。
3. **就业面向**：主要就业岗位 + 相近 / 发展岗位（来自 PGSD 岗位画像）。
4. **设计理念**：能力本位、项目驱动、岗课赛证融通、AI / 数字化融入。
5. **能力目标**：专业 / 方法 / 社会 / 发展四类（或知识/能力/素质），写成"能 + 行为 + 产出"，直接引用 PGSD 拆解产出的表述。
6. **内容结构**：模块化骨架（M1…Mn），列模块名、对应岗位任务、学时；**只到模块层**，项目与周次留给整体设计。
7. **考核标准**：过程性 + 终结性；分级行为（合格 / 良好 / 优秀）直接对接 PGSD 初/中/高三级；作品集为核心产出。
8. **实施保障**：师资、实训条件、资源（微课 / 动画 / 教材）、数字化平台。
9. **特色创新**：智慧课程要素（AI 助教、自适应路径、学习数据画像、个性化推送）。

## 附录（评审重点，必配）

- **附录 A：PGSD 能力分级标准表**——逐能力点写三级行为锚点。
- **附录 B：岗位能力画像表**——每个典型岗位的 PGSD 主次映射。
- （如有）**赛教融合映射表**：竞赛·单元·类别 → 模块 → PGSD → 产出（含时长/规格等硬指标）。

## 单元设计要素（下游衔接提示）

- 任务 / 项目载体、学习目标、重难点、教学活动（教 / 学 / 做）、资源（微课 / 动画）、评价点（对接 PGSD 行为）。
- 单元设计须同时对齐两层：从课标取能力目标/评价结构/岗课赛证口径；从整体设计取模块落点/真实任务/课时分配。

## 精品课 / 智慧课程评审要点（提炼）

- **精品课**：优质资源（微课 / 动画 / 教材）、线上线下混合、教学效果、辐射共享。
- **智慧课程**：AI 融入（智能助教 / 个性化推送 / 学习画像）、数据驱动、沉浸式交互。
- **共性**：就业导向明确、能力标准清晰、真实项目载体、可测量考核、**每个口径有据可查**（数据来源、赛事通知、证书标准）。

## 与九步工作流的衔接

- Step 2 就业调研 → "就业面向"依据 + 课程定位"岗"线。
- Step 3 区域调研 → 课程定位"区域对接"落地句。
- Step 4 证书调研 → 课程定位"证"线 + 考核课证融通点。
- Step 5 竞赛核对 → 课程定位"赛"线 + 赛教融合映射表。
- Step 7 PGSD 拆解 → "能力目标""考核标准" + 附录 A/B。
