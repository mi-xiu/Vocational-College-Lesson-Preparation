# 智慧职教图谱（ti-zhihui-zhijiao-graph）

帮助课程建设项目，把一份**只有节点名骨架**的智慧职教知识图谱 xlsx，按平台规范补全成**属性全齐**的完整图谱。它本身**绝不改动一/二/三级节点名**，只填"名字之外"的列。

严格的 25 列结构（0 索引）见 `references/column-structure.md`；本文件聚焦工作流、硬规则与工具坑。

## 一、铁律（任何情况下不可违反）

1. **一/二/三级节点名（C6/C8/C10）逐格原样保留**：包括"三级名为空"的任务行（如考核/期中/练习行），一字不改、一个空白格也不动。
2. **节点数量不增不减**：一级 / 二级 / 三级点行数，与原文件完全一致。禁止从 .md / 其他素材新增三级点，也禁止删除任何行。
3. **所有空格都要填**（有意的空白除外，见下）：除 C9（二级描述，原文件本就没描述的任务行可留空）与 C12（末级节点类型，仅三级点行填"技能"，非末级行留空）外，其余属性列对每一数据行都必须有值。
4. **推断列一律前缀「（推）」**：凡原文件/素材里没有现成出处、由本技能推断填上的内容，前缀「（推）」以便用户逐格核对。事实列（赛事名/赛项名/证书名）若带推也保持前缀一致。
5. **缺失内容推断优先级**：本地工作空间素材 → 本课程项目文件 → 网络核实（赛事/证书须 web 核实真实名称后再写）。

## 三、工作流

### 第一步：只读读取原文件骨架（注意字段名！）
- 用 `tencent-docs-routing` 路由到 `tencent-local-office-edit` 技能，调用其 `edsdk.py`。
- 读取单元格**必须用 `string_value`**（不是 `value`！）；`value_type` 必须大写 `'STRING'`。
- 先 `sheet_get_sheet_info` 拿真实 `sheet_id`（常见 `000001`），再 `sheet_get_cell_data` 读全列。
- 解析出：每个数据行的层级（C6 有值且无 C8/C10→一级；C8 有值无 C10→二级；C10 有值→三级）、C6/C8/C10 名字（含空白）、原文件已填列。

### 第二步：建立名字权威快照
- 把原文件 C6/C8/C10 每个格子的（行号, 列, 值）存为权威字典，**含空字符串**。
- 后续一切生成都以此为唯一基准；绝不新增、删改、重排任何节点名。

### 第三步：抽取/确认规范词汇
- 若同项目已有填好的图谱文件，复用其 C16/C17/C20/C23/C24 口径保持一致。
- 课程特异性字段（赛事/证书）向用户确认或 web 核实。

### 第四步：生成属性（镜像原文件布局）
- 输出行 = 原文件数据行（行号、层级一一对应），**不增行、不删行**。
- C6/C8/C10 直接拷贝原值（含空白）。
- 其余列按第二节规则逐行生成（用 `string_value`）。
- 先 dry-run 打印前若干行 + 节点计数（一级/二级/三级）给用户预览，无误再写回。

### 第五步：写回（clear + set，避免 csv bug）
- **不要用** `sheet_set_range_value_by_csv`（长期报 "expected N+1" 诡异 bug）。
- 正确做法：
  1. `sheet_clear_range_cells` 清空数据区（如 row3–199, col0–24）；
  2. `sheet_set_range_value`，`values = [{"row":R,"col":C,"string_value":"V","value_type":"STRING"}, ...]`，**分批 ≤ 2500/批**；
  3. 字段名一律 `string_value`。
- 写回后**必须落盘**：`save_file`。

### 第六步：落盘与锁文件处理
- 若 `save_file` 报 `"Export file is occupied"`（Obsidian 或 Tencent Docs 预览占用源文件），**不要反复重试**，改用 `save_file(file_path=新名)` 另存为 `{原名}（vN已填）.xlsx` 绕过锁。
- 提示用户：源文件未改动；确认无误后可把新文件覆盖回原名（用户关闭预览后）。

### 第七步：分批读回零差异校验（关键！）
- 单次 `sheet_get_cell_data` 大响应会被**截断**（cells 数偏低，是假象），必须**分批**读回（如 row3–65 + 66–130）再拼接。
- 校验项：
  1. C6/C8/C10 与原文件权威快照**逐格比对，0 处不一致**（含空白格）；
  2. 一级/二级/三级点行数与原文件**完全一致**（集合相等，无缺失、无新增）；
  3. 空白 C10 行号集合与原文件一致；
  4. 数据行属性列（除有意的空白 C9/C12 外）无空格。
- 校验全过才交付；有任何不一致立即回查生成逻辑，不将就。

## 四、工具坑速查（来自实战）

- **字段名 `string_value`**：`sheet_get_cell_data` / `sheet_set_range_value` 的单元格值键是 `string_value`，不是 `value`。读错会误判文件为"空"，写错不落盘。
- **避开 `_by_csv`**：`sheet_set_range_value_by_csv` 永远少一列 bug，用 `sheet_set_range_value`。
- **响应式 JSON-RPC**：`edsdk._rpc("tools/call", {...})` 返回的单元格在 `content[0].text`（JSON 字符串），需 `json.loads` 后取 `cells`。
- **异步打开**：`open_file` 可能异步，读不到时重 `open_file` 一次再读。
- **预览锁**：源文件被占用时 `save_file` 失败 → 另存新名。
- **读回截断**：大范围读回需分批，否则校验数字失真。

## 五、关键原则

- **名字不可侵犯**：本技能的唯一红线——节点名（含空白）原样进出，任何"顺手优化名字"都是错误。
- **先预览后写回**：生成矩阵先 dry-run 给用户看结构，确认再落盘。
- **（推）透明**：所有推断列带前缀，方便用户核对修正。
- **课程特异须核实**：赛事/证书等事实字段，宁可问/查，不臆造。
- **校验闭环**：写回后分批读回做零差异校验，不靠"写入成功"就交付。
