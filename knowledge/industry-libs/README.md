# industry-libs · 使用说明（knowledge/industry-libs/）

> 行业顾问「行顾问」的多专业知识库架构——**加载哪个库，就是哪个行业的顾问**。

## 目录结构

```
knowledge/industry-libs/
├── _template/        # 知识库结构模板（新专业从这初始化）
├── film/         # ⭐影视库（默认，方法级示例）
├── ecommerce/    # 电商（空库，按需初始化）
└── accounting/   # 会计（空库，按需初始化）
```

## 新专业初始化（如《电商运营》）

1. 复制 `_template/` → `ecommerce/`
2. 用户提供电商教材/资料 → 行顾问解析 → 填 教材解读/案例台账/工艺方法/岗位场景
3. 流程专家照常工作（①调研/②图谱…不变）

## 知识库生命周期

```
初始化（用户教材）→ 运行（增量更新）→ 升级（用户反馈优化）→ 归档（沉淀复用）
```

## 红线

- 版权教材只存解读方法，不存原文。
- 案例标注来源与授权。
