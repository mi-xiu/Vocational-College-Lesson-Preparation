# 行业知识库结构模板（_template）

> 新专业初始化时复制本模板 → 按专业填内容。结构即标准。

## 文件清单

```
<专业>/                    # 如 ecommerce/
├── README.md              # 本专业知识库说明（专业/教材/案例来源）
├── 教材解读.md            # 教材章节 → 能力点/项目 映射（三态判定）
├── 案例台账.md            # 行业真实案例（来源/授权/用途）
├── 工艺方法.md            # 行业工艺/类型方法/新工艺新技术
└── 岗位场景.md            # 岗位对应的真实工作场景（供 ①调研/②图谱 素材）
```

## 教材解读.md 模板

```
# <教材名> 解读
## 章节映射表
| 章节/任务 | 主题 | 支撑能力点 | 判定（✅/⚠️/❌） |
|---|---|---|---|
## 三态判定说明
- ✅ 直接落地：课堂精读/练习
- ⚠️ 需改造：适配课程体量（节选/微缩）
- ❌ 无法落地：自编活页补材
```
