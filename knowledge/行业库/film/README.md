## 一、教材解读法（适用于影视创作类教材）

### 核心方法：无对白练习 = 人物动作叙事（画面造型想象力）
- **教材原意（实证）**：无对白 ≠ 无声的物，而是**人物动作/状态/关系**叙事——物为氛围，非主角。
- 教学落地：入门项目用"情境命题卡"（情境/人物动作提示/无对白要求/评价要点），学生自创。
- 范例拆解（教学引用）：《一无所有》（街头歌手+人流=孤独）、《两个人的沉默》（对坐沉默=张力）。

### 三态判定法（教材章节 → 能力点/项目映射）
| 判定 | 含义 | 处理 |
|---|---|---|
| ✅ 直接落地 | 章节内容直接支撑能力点 | 课堂精读/练习 |
| ⚠️ 需改造 | 内容适配微电影体量（30-60s/90s/3-8min） | 节选/微缩 |
| ❌ 无法落地 | 教材盲区（类型方法等） | 自编活页补材（1号文活页教材方向） |
