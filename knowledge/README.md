## 排除范围（不入包）
- **校级/专业级内容**：学校人才培养方案、专业特定模板（如 A04-专业文件）、智慧职教平台导入模板（知识图谱 xlsx）——随课程私有，不随专家团分享。
- **版权教材**：出版社教材原文（如微电影剧作教程）——引用书目可在课标/备课包登记，不入知识库。

## 使用规则
1. 1号文口径（政策链 = 纲要第22条 → 三年行动计划 → 1号文 → 国规教材遴选通知）以解读 md 为准；
2. 验收话术须具体到工具工艺（如"即梦 Seedance 2.5 文生视频工作流、可灵 3.0 多镜头叙事流程"），不写笼统"融入AI"；
3. 引用原件时标注来源版本与时间，可追溯。
